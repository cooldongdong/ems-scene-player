# scenarios／情境

一個檔一個情境，檔名就是它的 `id`。**新增一個情境 = 新增一個檔**，不必改任何其他地方。

情境是一場訓練的完整劇本：素材組合（環境 × 急救事件）＋ 一串照順序演的簡報頁。

為什麼要有這一層：

1. 三個選單可以排出 5×6 = 30 種基本組合，但素材庫不是每一格都填滿。情境是「這組確定跑得動」的**人工背書名單**。
2. 光有素材還不夠——訓練需要的是「先發生什麼、再發生什麼」。`slides` 就是那條時間線。

一頁 = 一組疊起來的圖層（`layers`），宣告「這一頁畫面上有什麼」。播放就是換頁：按一次前進換一頁，教官決定節奏。

## index.yaml 是什麼

`index.yaml` 是**自動產生的檔名清單，不要手改**。

純靜態網站沒有辦法問伺服器「這個資料夾裡有什麼」——HTTP 沒有這個動詞——所以首頁只能照著這張清單一個一個去抓。真相是資料夾本身，`index.yaml` 是副本。

- 本機新增或刪除情境檔之後：`node tools/build-scenarios-index.js`
- GitHub 上不用管：push 到 `main` 之後 workflow 會自動重新產生

> ⚠️ 不要改成「讀伺服器自動生的目錄列表」。`python3 -m http.server` 會生一頁，GitHub Pages **不會**（沒有 `index.html` 的資料夾直接 404）。那種寫法本機測起來全綠，一上線全掛。

## 情境的欄位

| 欄位 | 說明 |
|---|---|
| `id` | 必須唯一且穩定，用 ASCII kebab-case，**且要跟檔名一致**。它是自訂情境覆蓋內建情境的比對依據——改了 id 等於變成另一個情境，使用者存在瀏覽器裡的修改會對不上而失效 |
| `name` | 清單上的字，越短越好 |
| `note` | 滑鼠停留時的說明，可省略 |
| `environment`／`medicalEvent` | 值必須和 `scenario-data.yaml` 的 `options` 完全一致，對不上整筆會被跳過 |
| `ambience` | 整場的環境聲音。預設 `auto`（依情境條件挑），填 `none` 就是這場不要環境聲音 |
| `slides` | 至少要有一頁，否則整筆會被跳過——空白的情境比不存在更難懂 |

**不要寫 `complications` 欄位。** 這個情境用到哪些突發狀況，是從所有「啟用中」的簡報頁的 `greenscreen` 圖層自動推導出來的。多寫一份就是第二份真相。

`ambience` 放在情境層級而不是頁圖層，因為環境聲音是唯一會 loop 的角色；做成頁圖層的話每換一頁就會從頭重播，現場聽起來會像斷掉。

## 簡報頁（slides）

| 欄位 | 說明 |
|---|---|
| `id` | 情境內唯一即可，省略時自動編成 `s1`、`s2`…… |
| `title` | 清單上顯示的字 |
| `note` | **給教官看的提詞，不會投影出去。** 要投影給學員看的字請用 `text` 圖層——這兩個混掉的後果是把教官的提詞投到大螢幕上 |
| `enabled` | 只有明確寫 `false` 才是關閉。關掉的頁**播放時會跳過，但仍留在清單裡**，用途是現場臨時抽掉一個橋段，不必真的刪掉它。省略視為啟用 |

每頁至少要有一個圖層，否則該頁會被跳過。

## 圖層（layers）

**順序由型別決定，寫在陣列裡的順序不影響輸出**（投影視窗的 z-index 是寫死的）：

| 型別 | 說明 | 欄位 |
|---|---|---|
| `scene` | 環境（最底層，滿版） | — |
| `patient` | 病患照片 | `size`／`x`／`y` |
| `greenscreen` | 去背人物 | `complication`（必填）、`segment`、`size`／`x`／`y`／`tolerance` |
| `text` | 投影給學員看的字 | `text`（必填）、`size`／`x`／`y` |

每種型別一頁最多一個。`greenscreen` 是硬限制（投影視窗一次只有一個 canvas），其餘是刻意簡化。

`scene` 與 `patient` 每頁必備，**沒寫會自動補上**，所以手寫時可以省略。

每個圖層可以填 `asset: <素材 id>` 把素材釘死；不填就是 auto——依情境條件挑，重新產生會換一張。要所見即所得地排版就釘選，要每次有點變化就留 auto。

`size`／`x`／`y`／`tolerance` 省略時用預設值（patient 85/50/57、greenscreen 70/50/55/40、text 40/50/50），所以只需要寫你真的調過的那幾個。

多片段的突發狀況（例如「肇事雙方爭吵」有 3 段）**展開成連續多頁**，各釘一個 `segment`。圖層是靜態的，描述不了「演完第一段換第二段」；展開成頁之後，每一段都可以改標題、關掉、排序、加自己的說明文字。

## 目前這 7 組的來源

把 30 種基本組合逐一比對素材庫後，四個角色（環境影像、環境聲音、病患照片、病患聲音）都取得到素材的就是這 7 組。

這只代表「素材齊全」，**不代表「情境合理」**——實際播過覺得不合適就直接改掉那一筆。

## 不用手寫也可以

在網頁上編好情境之後，編輯畫面有「匯出這個情境」，下載下來的檔名與內容就是這個資料夾要的樣子，原樣丟進來即可。
